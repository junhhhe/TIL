# AWS S3 (Simple Storage Service)

AWS S3는 확장성이 뛰어난 객체 스토리지 서비스. 사실상 무제한의 데이터를 저장할 수 있으며, 높은 내구성(Durability)과 가용성(Availability)을 제공하여 웹 호스팅, 백업, 빅데이터 분석 등 광범위한 용도로 사용

---

## 1. S3 핵심 개념 및 특징

### 1.1. 객체 스토리지 (Object Storage)
* **파일 시스템 vs 객체 스토리지:** EC2의 EBS(블록 스토리지)나 일반 서버의 파일 시스템과 달리, S3는 데이터를 파일이 아닌 **객체(Object)** 형태로 저장
* **객체 구성:** 객체는 **데이터 자체**와 **메타데이터(Metadata)**, 그리고 키(Key, 고유 이름)로 구성
* **무제한 확장성:** S3는 저장 용량의 제약이 거의 없으며, 필요한 만큼 스토리지가 자동으로 확장

### 1.2. 버킷 (Bucket)
* **정의:** S3에 객체를 저장하기 위한 **최상위 컨테이너**
* **특징:**
    * **전역적 고유 이름:** 버킷 이름은 AWS 전역에서 유일해야 함
    * **리전 지정:** 버킷은 특정 AWS 리전(Region)에 생성
    * **액세스 제어:** 버킷 단위로 접근 정책(Bucket Policy) 및 ACL(Access Control List)을 설정하여 보안을 관리

### 1.3. 내구성 및 가용성
* **내구성 (Durability):** 99.999999999% 의 매우 높은 내구성을 보장. 이는 데이터를 여러 가용 영역(AZ)에 복제하여 안전하게 보관한다는 의미
* **가용성 (Availability):** 일반적으로 99.99% 이상의 높은 가용성을 제공

## 2. S3 스토리지 클래스

S3는 데이터 접근 빈도, 복원 시간, 내구성 요구 사항에 따라 다양한 스토리지 클래스를 제공하여 비용을 최적화할 수 있도록 함

| 클래스 이름 | 주요 특징 | 접근 빈도 | 비용 (저렴한 순) | 사용 사례 |
| :--- | :--- | :--- | :--- | :--- |
| **Standard** | 높은 가용성, 빠른 액세스 | 높음 | 중간 | 자주 액세스하는 데이터, 웹 콘텐츠 |
| **Standard-IA** | 낮은 액세스 비용, 검색 시 요금 | 낮음 (월 1회 미만) | 낮음 | 장기 백업, 재해 복구 파일 |
| **One Zone-IA** | Standard-IA와 유사하나, 단일 AZ에만 저장 | 낮음 | 매우 낮음 | 복원 가능하지만, 자주 액세스하지 않는 데이터 |
| **Glacier Instant Retrieval** | 수 밀리초 단위의 빠른 검색, 장기 보관 | 매우 낮음 | 매우 낮음 | 아카이브가 필요하지만 빠른 액세스가 필요한 데이터 |
| **Glacier Flexible Retrieval** | 시간 단위로 복원 시간 선택 가능 (대부분의 아카이브) | 극도로 낮음 | 가장 낮음 | 장기 아카이브, 컴플라이언스 데이터 |
| **Intelligent-Tiering** | 액세스 패턴에 따라 자동으로 클래스 이동 | 다양함 | 가변적 | 액세스 패턴을 예측할 수 없는 데이터 |

## 3. S3 주요 기능

### 3.1. 버전 관리 (Versioning)
* **역할:** 객체의 실수로 인한 삭제나 덮어쓰기(Overwrite)로부터 데이터를 보호
* **작동:** 버킷 내의 모든 객체에 대해 변경될 때마다 고유한 버전 ID를 부여하여 이전 버전을 유지. 비활성화된 후에도 기존 버전들은 유지

### 3.2. 수명 주기 관리 (Lifecycle Management)
* **역할:** 객체의 생성 시점 또는 마지막 액세스 시점을 기준으로 스토리지 클래스를 자동으로 전환하거나 객체를 삭제하도록 규칙을 설정

### 3.3. 버킷 정책 (Bucket Policy)
* **역할:** IAM Policy와 유사하게 JSON 형식으로 작성되며, 버킷 레벨에서 접근 권한을 정의
* **특징:** 익명 사용자, 특정 AWS 계정, 특정 IP 주소 등 다양한 조건에 따른 접근을 허용/거부할 수 있음

### 3.4. 정적 웹 사이트 호스팅
* **역할:** S3 버킷을 사용하여 HTML, CSS, JavaScript 등으로 구성된 정적 웹 사이트를 호스팅할 수 있음 (동적 처리는 불가능)
* **구성:** 버킷 설정에서 정적 웹 사이트 호스팅을 활성화하고, 인덱스 문서(Index Document)와 오류 문서(Error Document)를 지정
